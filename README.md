# 🧠 PDF Brain

AI-powered PDF Q&A system with RAG, Voice, and Analytics.

## ✨ Features

- 📄 **Text PDF** support
- 📷 **Scanned PDF** support (OCR)
- 📊 **Table extraction** + Charts
- 💬 **Chat** with streaming
- 🎤 **Voice input** (नेपाली/English/हिन्दी)
- 🔊 **Voice output** (TTS)
- 🖼️ **Image analysis**
- 👥 **Multi-user** login
- 📈 **Analytics dashboard**
- 💾 **Export** (TXT/HTML/PDF/DOCX)
- 🔍 **Hybrid search** + Reranking
